# CodeMate

本地代码智能体，Go 实现。在终端里读取仓库、修改文件、执行命令，按多步任务推进；工具调用走文本协议，上下文按预算分节装配，会话状态保存在本地，中断后可以继续。

## 能力

- **回合循环**：拼 prompt、请求模型、解析应答、执行工具、结果回灌，直到模型给出最终答案。工具步数与模型重试分别计数，步数用尽后追加一次收尾请求，要求模型只给最终答案。
- **工具协议**：模型每次只返回一个 `<tool>...</tool>` 或 `<final>...</final>`。格式不合法时不重试同一请求，而是把格式提示写回历史，让模型看到自己的错误再改；连续失败到上限才停下。
- **内置工具**：`list_files`、`grep_files`、`read_file`、`write_file`、`edit_file`、`patch_file`、`run_command`、`load_skill`，统一注册、统一参数校验、统一执行入口。
- **上下文治理**：一轮 prompt 分五节（前缀、记忆、相关笔记、历史、当前请求），各有预算与下限；总量超上限时按固定顺序收缩。历史按新旧分层，近期条目保留正文，旧条目压成一行并按键去重。
- **权限审批**：路径越界、危险命令、文件改动三道门，拒绝原因回传模型，由模型另选路径。
- **文件改动评审**：写盘前生成 unified diff 供确认。
- **会话恢复**：历史与工作区指纹一起落盘；指纹不一致时不恢复，改为新建会话。
- **运行工件**：每次运行的模型请求、解析结果、工具执行按事件流落盘，事后可查。
- **技能**：扫描 `SKILL.md`，按需加载正文。

## 构建

```bash
go build -o bin/codemate ./cmd/codemate
```

## 评测

仓库带一套固定任务集，用工作区结果判定，不看模型自述。

```bash
go run ./cmd/eval -out report.json
```

每条任务输出一行（通过与否、请求次数、工具步数、prompt 字符数、失败原因），末尾给汇总：通过率、平均请求次数、平均工具步数、平均 prompt 字符数、工具失败率。

`-limit N` 只跑前 N 条；`MINI_CODE_MODEL_MODE=mock` 可以离线跑通链路，但结果全部失败，只用于验证流程。

## 配置

模型配置放在 `~/.mini-code/settings.json` 或项目内的 `.mini-code/settings.json`，支持 OpenAI 兼容与 Anthropic 兼容两类接口。

## 已知边界

单机单用户，没有并发与多租户设计。

`run_command` 靠审批与白名单约束，不是沙箱隔离，没有资源限额。

工具调用走文本协议：不接 MCP，也没有原生 function calling。代价是依赖模型遵循格式，格式遵从度差的模型会频繁解析失败。
